# TRIM-edicine Website

Modern static HTML5 rebuild of the TRIM-edicine corporate website.

## Initial build

The `initial-build` branch contains the first complete redesign using semantic HTML5, modern responsive CSS, and minimal vanilla JavaScript.

### Pages
- Home
- Technology
- Pipeline
- About
- Leadership
- News
- Contact
- Custom 404

### Principles
- No WordPress, database, Composer, page builder, jQuery, or theme dependency
- Preserve key legacy public URLs
- Keep historical scientific and business claims conservative until current 2026 status is verified
- Production is intended for DreamHost after staging review
- Current preview uses the orange-red TRIM-edicine/SoulMedic variant (`#EB594A`) rather than the cyan default theme

### Before production launch
- Verify current pipeline stages
- Verify leadership titles and affiliations
- Verify mailing address and phone number
- Migrate selected legacy images and brand assets locally
- Expand historical news/article archive where useful
- Configure production redirects and contact form handling
